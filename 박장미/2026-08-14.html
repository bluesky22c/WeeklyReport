1. Auto Exposure(A/E) 기능 현장 테스트 (08/10~11)


 - Align, Mapping, Pixel(Sparse) 검사 시퀀스별 A/E 동작 검증

 - 목표 평균 밝기, 오차 허용 범위, Threshold, ROI, 측정 채널, Exposure 범위를 기준으로 밝기를 측정하고 목표 범위 이탈 시 Exposure 자동 조정 후 재촬상하는 흐름 확인

 - Red/Green/Blue 측정 채널 및 복수 레시피 조건으로 총 68회 시험, 67회 A/E 결과 정상 반환 (1회는 시험 중 작업 중단으로 촬상 취소)

 - 완료 시험 Align 27회 / Mapping 23회 / Pixel(Sparse) 17회, 평균 보정 횟수 1.70 / 2.09 / 2.35 Step

 - 이 중 28건은 초기 촬상 조건에서 보정 없이 0Step OK 판정


2. A/E 최종값 재사용 기능 개발 (08/10~11)


 - A/E 완료 후 최종 Exposure를 해당 시퀀스 레시피 값에 반영하고 recipe.json에 자동 저장하도록 수정

 - Align은 Align Exposure, Mapping은 Mapping Exposure, 일반 검사는 Scan Exposure, Sparse 검사는 Sparse 필터 Exposure로 분리 반영

 - 업데이트 적용 이후 레시피 반영 로그 56건 전량 정상 저장, 저장 실패 없음

 - 이전 검사에서 저장된 Exposure가 다음 검사의 Recipe Base/Start Exposure로 사용되는 연속 동작 로그 확인

 - ND 필터는 A/E 가변 제어 대상에서 제외, 시퀀스/Sparse 필터 레시피의 고정 설정값 유지


3. 고객사 요청사항 반영 및 당일 검증 (08/12)


 - 제어 프로그램의 Tact Time / 이력 조회 탭 미연결 건 보완 완료, 고객사 요청에 맞게 화면 구성 수정

 - 화면 가장자리 픽셀 왜곡 보완을 위한 Target 영역 중앙 검사 기능 추가 — Mapping 후 유저가 선택한 NxM 영역 중간으로 Stage X,Y 이동 후 Image AF 재실행하고 검사 진행 (On/Off 선택 가능, 검증 완료)

 - Grab Point List 편집 기능 추가 — 유저가 Col, Row 입력 후 매뉴얼 Align/Mapping 완료 시 입력된 Grab Point의 X, Y를 연산해 해당 위치로 이동 (검증 진행 중)


4. 산출물 및 조회 방식 개선 (08/10~11)


 - RESULT 파일 내용을 고객사 요청 계산식 반영하도록 수정

 - 고객사 요청에 따라 일부 산출물의 저장 방식 및 경로 변경

 - Control 프로그램의 제품 이력 및 Tact 화면을 Cell Log 기반 조회 방식으로 정리, 현장 Control 프로그램에서 정상 동작 확인
