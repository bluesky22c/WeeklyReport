SFA Micro LED-N SWP 설비용 전계인가시스템

  1. 실장비 IO 테스트 및 프로그램 테스트 수행 (100%) - 아래 2~4번은 테스트 중 발견된 문제 수정
  2. DIO(UR20) 출력 통신 수정 (90%) - 코일 주소 0x8000 적용, 읽기 개수 실측 반영, 스레드 락 추가 / 출력 IO 맵 재작성 진행중
  3. 계측기 통신 안정화 (100%) - LCR 핸드쉐이크 재시도·COM 포트 누수·자동 재연결 중단 수정, 오실로스코프 재연결 경합 NRE 수정
  4. 전력량계(Accura 2500) 연동 (90%) - 레지스터 실측 확정, 3상 최댓값 기준 과전류 알람 / 전력량(Wh) 판독 별도 작업 필요
  5. 알람 실동작화 및 표시 개선 (100%) - 신호탑·부저 실동작 연동, EMS 상시 감시, 활성 알람 다중 표시, 좌/우 장치별 분리, 후면 이미지 추가, 알람 원인·조치 한글화
  6. 화재/온도/도어 감시 추가 (85%) - DeviceSafetyControl 연동, 기준값 설정 창, DI 알람 신설 / 실장비 COM·SlaveId 검증 미완
  7. 화면 UI 개편 (100%) - 메인 PIN RECIPE INFO 중계기판/BP 동시 표시, 오실로스코프 패널 기판별 분리, I/O LOG 탭 신설, 레시피 파형 편집기 CH1/CH2 구분
